이 기기에서 처음 열었어요. 노트와 기록이 있는 비공개 레포 를 읽고 쓰는 GitHub 토큰을 한 번 넣어 주세요. 토큰은 이 기기의 브라우저에만 저장돼요.

토큰 만드는 법
  1. GitHub에 계정으로 로그인한 뒤 새 토큰 만들기(Fine-grained)를 엽니다.
  2. Token name은 min-viewer, Expiration은 원하는 기간으로 정합니다.
  3. Repository access → Only select repositories → 만 고릅니다.
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token → github_pat_로 시작하는 토큰을 복사해 위에 붙여 넣습니다.
